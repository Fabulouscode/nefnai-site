# NEFNAI website

The new website for NEFNAI (New Followership, New Africa Initiative), built by ConceptLab.

Next.js 16, React 19 and Tailwind CSS 4. Colours come from the NEFNAI logo (green, laurel blue, sun gold); headings use Plus Jakarta Sans and body text Inter.

```bash
npm install
npm run dev   # http://localhost:3000
```
